# Current-base factory audit

This `factory/*` ref is an auditable hold point, not a catalog publication.
It is based exactly on public `main` at revision 19 and contains no new game
pack, no catalog revision, and no private App material.

The installed bounded engines can express three additional mechanic families,
but the current App registration exposes Solo/local-Bot launch only for the
card-turn, grid-board, and sliding-grid families. The accompanying audit records
the smallest App capability change needed before a real 3–5 game batch can pass
the Fast Gate. Until that change is available, no parameter-only or multiplayer-
only substitute is submitted.
